🇨🇮 EPS Côte d’Ivoire

📚 Présentation

Bienvenue sur EPS Côte d’Ivoire, un site dédié à l'Éducation Physique et Sportive en Côte d’Ivoire.

Le site a pour objectif de mettre à disposition des enseignants et des élèves des ressources utiles pour les cours d'EPS.

🎯 Objectifs

- 📖 Proposer des cours d'EPS
- 📝 Mettre à disposition des fiches de séances
- 🏃 Présenter les différentes activités physiques et sportives
- 📚 Faciliter l'accès aux ressources pédagogiques
- 🇨🇮 Promouvoir l'Éducation Physique et Sportive en Côte d'Ivoire

📋 Contenu du site

Le site pourra proposer :

- Cours d'EPS
- Fiches de leçons
- Fiches de séances
- Exercices pratiques
- Athlétisme
- Sports collectifs
- Sports individuels
- Conseils pour les enseignants
- Ressources pédagogiques

💻 Technologies utilisées

- HTML
- CSS
- JavaScript
- GitHub Pages
