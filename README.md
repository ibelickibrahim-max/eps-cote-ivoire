# EPS Côte d'Ivoire

Bibliothèque de ressources partagée pour les cours d'Éducation Physique et Sportive (EPS).

## 🎯 Objectif

Ce projet centralise et organise des documents pédagogiques (fiches de cours, PDF, supports) destinés aux enseignants d'EPS, afin de faciliter le partage et l'accès aux ressources.

## 📂 Contenu

- Fiches de séances par discipline
- Documents pédagogiques (PDF, Word)
- Ressources classées par niveau / thème

## 👥 Public visé

Ce projet est destiné aux professeurs d'EPS souhaitant accéder à des ressources prêtes à l'emploi ou partager leurs propres supports.

## 🚀 Utilisation

1. Parcourir les dossiers selon la thématique recherchée
2. Télécharger les fichiers nécessaires
3. Contribuer en ajoutant vos propres ressources (voir section Contribution)

## 🤝 Contribution

Les contributions sont les bienvenues ! N'hésitez pas à proposer de nouveaux documents ou à signaler des erreurs.
